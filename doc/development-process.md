[docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md). Follow that document for branch
naming, GitHub Flow, pull requests, required checks, non-author review, and squash
merges into `main`. The [software development plan](../docs/software-development-plan.md)
remains the delivery-sequence source.

Historical implementation evidence is in [yolo-player-tracking.md](yolo-player-tracking.md).

[experiment README](../experiments/player-tracking-yolo/README.md).

[docs/agent-decisions.md](../docs/agent-decisions.md). Local passing checks do not
