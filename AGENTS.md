# Agent guide

This file is the entry point for working in this repo. Long project documents live in `docs/` and are read on demand.

## Read before you decide

Open the file that matches the task. Leave the others closed.

| When | Read |
| --- | --- |
| Scope, users, or product decisions | `docs/project-proposal.md` |
| Process, milestones, or sequencing | `docs/software-development-plan.md` |

## Working in this repo

- Treat `docs/project-proposal.md` as the source for what the product is and who it is for.
- Treat `docs/software-development-plan.md` as the source for how the work is sequenced.
- When a task touches product scope or delivery process, read the matching doc before changing code or plans.
- Keep new always-on instructions in this file, and keep them short. Put longer reference material in `docs/`.
